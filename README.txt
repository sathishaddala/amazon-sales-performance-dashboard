# Amazon Sales Performance Analysis 📊

An Excel-based analysis of Amazon sales data (2025), covering product performance, category trends, regional sales, payment behavior, order status, and top customers — built with pivot tables, charts, and a summary dashboard.

## 📁 Project Structure

The workbook (`Amazon_Sales_Analysis.xlsx`) contains 5 sheets:

| Sheet | Description |
|---|---|
| `amazon_sales_data 2025` | Raw dataset — 250 orders with product, category, price, quantity, customer, location, payment method, order status, and date fields |
| `Business_Problem_statement` | 6 core business questions with supporting calculations |
| `pivot_tables` | Pivot tables summarizing sales by product, category, location, payment method, and order status |
| `dashboard` | Visual dashboard with charts and slicers summarizing key metrics |
| `Insights` | Final written insights and recommendations |

## 🧾 Dataset Fields

`Order ID`, `Date`, `Product`, `Category`, `Price`, `Quantity`, `Total Sales`, `Customer Name`, `Customer Location`, `Payment Method`, `Status`, `Month`, `Day Of Week`

## ❓ Business Questions Answered

1. Which products generate the highest total sales?
2. Which categories perform best?
3. Which cities (customer locations) show strong or weak performance?
4. How do payment methods influence orders?
5. What percentage of orders are delivered, cancelled, or pending?
6. Who are the highest-spending customers?

## 🔍 Key Insights

- **Highest-selling product:** Refrigerator ($78,000)
- **Best customer location:** Miami ($31,700)
- **Most popular payment method:** PayPal (60 orders)
- **Highest-spending customer:** Olivia Wilson ($36,170)
- **Order status split:** Completed (88) · Pending (85) · Cancelled (77)

## 💡 Recommendations

- Focus on high-performing products like Refrigerators to sustain sales momentum.
- Analyze demand drivers in Miami and other strong-performing cities to replicate growth elsewhere.
- Investigate the causes behind Pending and Cancelled orders to reduce operational drop-off.
- Ensure a smooth PayPal checkout experience, since it's the preferred payment method.
- Prioritize retention efforts for high-value customers such as Olivia Wilson.

## 🛠️ Tools Used

- Microsoft Excel — Pivot Tables, Pivot Charts, Slicers, Dashboard design

## 🚀 How to Use

1. Download `Amazon_Sales_Analysis.xlsx`
2. Open in Excel (pivot tables and slicers require desktop Excel — Google Sheets may not render slicers correctly)
3. Explore the `dashboard` sheet for a visual summary, or dive into `pivot_tables` for the underlying breakdowns
